# Roadmap

## M0 Foundation

**Goal:** the repository builds, tests and documents a first vertical slice.

Exit criteria:
- [ ] Build, test and lint pass on a clean checkout.
- [ ] The README explains how to run the first slice.
- [ ] The first release has a version and a changelog entry.

**Non-goals:** deployment beyond the development environment.

## M1 First useful slice

**Goal:** one user can complete the core task end to end.

Exit criteria:
- [ ] The acceptance criteria in `PROJECT.md` are covered by tests or recorded evidence.
- [ ] A reviewer can reproduce the result from the README.
